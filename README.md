# Football Club Manager Data Packs

Community Data Pack registry for Football Club Manager.

## Create a Player Name Data Pack

Download the starter pack:

[Download Players Starter Pack](https://github.com/KULLANICI_ADIN/manager-sim-data-packs/releases/download/starter-v1.0/ManagerSim-Players-Starter.zip)

The ZIP contains:

- `manifest.json`
- `players.csv`

### Rules

- Only edit the `name` column.
- Do not modify `playerId`.
- Other columns are provided only to help identify players.
- When finished, keep `manifest.json` and `players.csv` inside the ZIP.
