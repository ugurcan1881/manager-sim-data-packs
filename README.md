# Football Club Manager Data Packs

Community Data Pack registry for **Football Club Manager**.

Here you can download the official starter files, create your own Data Pack and submit it to be listed in the community Data Pack browser.

---

## Create a Player Name Data Pack

Download the starter pack:

### [⬇️ Download Players Starter Pack](https://github.com/ugurcan1881/manager-sim-data-packs/releases/download/starter-v1.0/ManagerSim-Players-Starter.zip)

The ZIP contains:

- `manifest.json`
- `players.csv`

The `players.csv` file contains all players with their unique `playerId`.

### Rules

- Only edit the `name` column.
- **Do not modify `playerId`.**
- `playerId` is used by the game to identify each player.
- Other columns are provided only to help identify players.
- Editing other informational columns will not change those attributes in-game.
- Keep `manifest.json` and `players.csv` inside the ZIP.

### Example

Before:

```csv
playerId,name,position,nationality
1524,John Smith,ST,Nigeria
```

After:

```csv
playerId,name,position,nationality
1524,Victor Osimhen,ST,Nigeria
```

When your Data Pack is ready, ZIP the files again and test it in-game using:

**Data Packs → Import ZIP**

# 📤 Submit Your Mod

Finished your Data Pack and want other players to download it?

## [SUBMIT YOUR DATA PACK](https://github.com/ugurcan1881/manager-sim-data-packs/issues/new?template=data-pack-submission.yml)

Fill out the submission form with:

- Data Pack name
- Author
- Version
- Description
- ZIP download URL
- Source page
- Game version
- Database version
- SHA-256

After the submission is reviewed and accepted, the Data Pack can be added to the in-game **Search Data Packs** list.

---

## Community Data Packs

Approved Data Packs can appear in the game's online Data Pack browser.

Players can:

- Search available Data Packs
- See the author
- See the original source
- Check version and download size
- Download the pack
- Install and use it in-game

---

## Data Pack Safety

Data Packs are data-only packages.

Executable files and scripts are not supported.

Packages may be removed if they:

- Contain malicious files
- Are broken or intentionally misleading
- Violate community rules
- Receive valid copyright or trademark complaints
- Attempt to execute external code
